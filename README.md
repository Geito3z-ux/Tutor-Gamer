# 🎮 Tutor Gamer - Videojuego Educativo RPG

**Tutor Gamer** es un videojuego educativo tipo trivia RPG donde los estudiantes responden preguntas para atacar monstruos y derrotarlos. Cada respuesta correcta hace daño al enemigo y cada error hace que pierdan vida.

## 📋 Características

- 🧍 **Sistema de Vidas**: El jugador comienza con 5 vidas
- ⚔️ **Sistema de Combate**: Responder preguntas correctas = daño al enemigo
- 🎯 **6 Niveles Progresivos**: Del 1° primaria al media superior
- 👑 **Boss Final**: Nivel más desafiante con preguntas complejas
- 🔥 **Sistema de Combos**: Respuestas correctas seguidas multiplican daño
- ⚠️ **Preguntas Trampa**: 1 por nivel para confundir
- 📊 **Perfil de Resultados**: Boleta con dominio por materia
- 📱 **Responsive Design**: Funciona en desktop, tablet y móvil

## 🎮 Cómo Jugar

1. Selecciona tu nivel educativo (Primaria, Secundaria, Media Superior)
2. Elige el grado específico
3. Comienza a responder preguntas
4. Respuestas correctas = daño al monstruo
5. Respuestas incorrectas = pierdes 1 vida
6. Derrota 6 monstruos para completar el juego
7. Visualiza tu perfil de rendimiento

## 📊 Sistema de Matemáticas

- **Primaria (1° a 6°)**: Según el grado (sumas, restas, multiplicación, etc.)
- **Secundaria**: Matemática de 1° secundaria (normal)
- **Media Superior**: Matemática de 1° secundaria (más compleja)
